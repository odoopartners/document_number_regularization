Document Number Regularization

Correct supplier document numbers without changing Odoo's internal accounting sequence.

What this module solves

Imported or historical vendor bills may keep an internal Odoo number in the Document Number field. This module lets an Accounting Manager update that value from Bill Reference while preserving the original accounting sequence and its audit trail.

Key features

  • Bulk action for vendor bills and vendor credit notes.
  • Validation of the XXXX-XXXX supplier reference format.
  • Preservation of the internal Odoo accounting number.
  • Original value, first update date and responsible user recorded for auditing.
  • Every document number update logged in the chatter.
  • Atomic processing: one invalid record cancels the complete selection.
  • Independent from country-specific localization modules.

How to use it

  1. Open the vendor bills list.
  2. Select the bills or credit notes to update.
  3. Choose Actions > Update Document Number from Bill Reference.
  4. Review the result and audit information in the Other Info tab.
Compatibility: Odoo 19 Community and Enterprise, Odoo.sh, Ganemo Online and Ganemo.SH.
